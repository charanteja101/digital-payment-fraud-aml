# Data

The raw data is not stored in this repository (the file is about 470 MB).

## Download

1. Go to https://www.kaggle.com/datasets/ealaxi/paysim1 (a free Kaggle account is needed).
2. Download the CSV (named `PS_20174392719_1491204439457_log.csv`).
3. Place it here as `data/paysim.csv`.

## About the dataset

PaySim is a **synthetic** dataset generated by a mobile-money simulator. It was built from aggregated statistics of a sample of real transaction logs from a mobile-money service in an African country, with fraudulent behaviour injected by the simulator. The paper behind it: E. A. Lopez-Rojas, A. Elmir and S. Axelsson, "PaySim: A financial mobile money simulator for fraud detection", EMSS 2016.

- About 6.36 million transactions over 744 steps (30 days, 1 step = 1 hour).
- About 8,213 fraud cases (0.13%).
- Fraud occurs only in `TRANSFER` and `CASH_OUT` transactions.
- `isFlaggedFraud` is the simulator's own rule: an attempt to transfer more than 200,000 in a single transaction.

| Column | Meaning |
|---|---|
| `step` | Hour of the simulation (1-744) |
| `type` | `CASH_IN`, `CASH_OUT`, `DEBIT`, `PAYMENT` or `TRANSFER` |
| `amount` | Transaction amount |
| `nameOrig` | Sender account (not used by the model; senders rarely repeat) |
| `oldbalanceOrg`, `newbalanceOrig` | Sender balance before and after the transaction |
| `nameDest` | Receiver account (names starting with `M` are merchants) |
| `oldbalanceDest`, `newbalanceDest` | Receiver balance before and after (no information for merchants) |
| `isFraud` | Target: 1 for fraud |
| `isFlaggedFraud` | The simulator's large-transfer flag |

## Known issues to keep in mind

- Because the data is simulated, results on it are not evidence of real-world performance. Models often score near-perfectly.
- A note on a related Kaggle version of the dataset warns that detected fraud is cancelled, so the balance columns should not be used. This repository therefore builds its main model **without the balance-after columns** and reports the effect of including them as an ablation.

Please follow the dataset's licence and citation requirements on Kaggle.
